# 甲 · 文生图(懒人句 → 长提示词)

八步,每步只定一件事,后步不翻改前步:

## 八步

1. **切两半**:钉死的(总纲第 2 条)vs 留白的(没提的全部由我决定)。短需求 = 要发明大部分画面,不是少写点
2. **定框**:默认横 3:2、竖 2:3;徽章/头像/专辑封面 1:1;电影/演示 16:9;手机屏/长横幅 9:16;其余比例只在题材真需要时用。比例只放进推荐值,永不写进描述正文
3. **开场句**(约 20 字/词):媒介 + 风格 + 主体 + 背景或色调,常带方向。媒介名词(照片/海报/插画/信息图/特写/卡片)永不省;风格词在此点名一次,结尾可回声
4. **先列清单再动笔**:每个元素带画框位置(左上/顶部横贯/下三分之一/正中……共 8~14 处,须够到四角四边和中心,不许挤在中间);每段要读的文字按阅读顺序列出
5. **走框**:
   - 分区图(海报/页面/界面/宽场景):背景与垫面(紧跟开场句,不放最后)→ 顶带(标题/天空)→ 身体(左→中→右,各一两句)→ 底带(页脚/前景/地面)
   - 单主体满框(肖像/特写/单体):背景及其退远 → 姿态与画框位置 → 头脸 → 身体与每件衣物 → 手持/接触物 → 边角余量
   - 约 1/3 句子以方位短语开头("画面右侧……""左上角……"),读者永远知道自己在看哪
   - 单段成文;真分层(卡片组/分栏/分镜)才分段,每段开头报位置
6. **逐段放文字**(整图无字则跳过——别给无字图发明招牌):每串"位置 + 样式(粗细/颜色/大小)+ 直双引号内容",保持原书写系统;远处的模糊招牌写"模糊/小到不可读",不发明字符;图表的轴标、图例、数值也是文字,要写出
7. **光照单独成句**:来源、方向、质感(左窗柔光/顶部硬光/低角度暖阳/平光),及其留下的影与高光
8. **收尾整帧一句**:平衡/对称、色调、风格、氛围("整体构图……")。只此一句,不追加第二总结

## 体量与语言

- 体量:约 20 句 / 400–500 词(中文约 500–700 字)。三词需求和三百词需求产出同等丰满;信息密集的图更长,纯静物可短,薄需求绝不买薄描述
- 语言:正文跟随用户语言(中文场景直接中文,Qwen2.1 中文消化无损);图内文字永远原文。(例外:走服务器 PE 节点自动改写时,其输出固定英文,属训练分布所定)

## 交付形态

炼好的提示词全文 + 推荐比例 + 一句关键取舍说明(可省)。
